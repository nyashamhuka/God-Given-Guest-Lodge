# God Given Guest Lodge

A modern hospitality landing page for God Given Guest Lodge, a premium guest lodge in Harare, Zimbabwe. The site showcases the lodge's rooms, gallery, guest reviews, and booking/contact experience across a responsive, elegant interface.

## Overview

This project is a static website built with HTML, CSS, and JavaScript. It includes:

- A luxury-themed homepage with hero section and reservation panel
- A dedicated rooms page with room details and gallery previews
- A gallery showcase with interactive lightbox behavior
- Guest review form and testimonial cards
- WhatsApp booking CTA and contact information
- Light/dark theme toggle and mobile-friendly navigation

## Running the Project Locally

Because this is a static site, you can open the files directly in a browser or serve them locally.

### Option 1: Open directly

- Open `index.html` in your browser.

### Option 2: Use a local web server

From the project root, run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
